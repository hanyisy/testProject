# 기술 구성 (1차 · 컨펌용)

기획서 15·16장 기준: 개인 저장소에서 더미 데이터로 끝까지 돌아가게 만들어 디자인과 동작을 컨펌받고, 이후 회사 저장소(비공개)로 옮깁니다.
화면은 새로 디자인하지 않고 `design/`의 확정 시안을 그대로 옮깁니다. 시안이 없는 화면만 같은 토큰·컴포넌트로 만듭니다.

## 한 줄 요약
Next.js(App Router, TypeScript) 앱 하나가 **랜딩 · 본사 어드민 · 파트너 관리자 · 파트너 공개 사이트 · API**를 모두 맡고,
DB는 **PostgreSQL**(Drizzle ORM)입니다. 컨펌 단계에서는 설치 없이 도는 **PGlite**(파일에 저장되는 Postgres)에 시안 데이터를 넣어 씁니다.

## 구성 요소

| 영역 | 선택 | 이유 |
|---|---|---|
| 앱 | Next.js 16 · App Router · TypeScript | 어드민·파트너·공개 사이트·API를 한 저장소, 한 배포로. 회사 이전이 쉬움 |
| 화면 | 서버 컴포넌트 + 필요한 곳만 클라이언트 컴포넌트 | 목록·상세는 서버에서 바로 그림. 시안의 즉시 반응(칩, 스위치, 탭)만 클라이언트 |
| 폼 | 진짜 `<form>` + 서버 액션 | 기본 전송이 그대로 동작(JS 꺼져도 전송). 랜딩 규칙과 같음 |
| 스타일 | 일반 CSS (시안 토큰 그대로 + 컴포넌트 클래스) | 시안이 인라인 스타일·CSS 변수로 되어 있어 값 그대로 옮기기 쉬움. 라이트/나이트 테마 |
| DB | PostgreSQL · Drizzle ORM · 마이그레이션 | 운영 DB와 같은 SQL. 스키마가 코드로 남음 |
| 컨펌용 DB | PGlite (`.data/pglite/`, git 제외) | Postgres 설치 없이 `npm run dev`만으로 실행. `DATABASE_URL`을 넣으면 실제 Postgres 사용 |
| 더미 데이터 | `scripts/seed.ts` — 시안 데이터 그대로 | 화면과 같은 숫자로 확인. `npm run db:reset`으로 처음 상태 복원 |
| 로그인 | 자체 세션 (DB 세션 + httpOnly 쿠키, 비밀번호 해시) | 공개 회원가입 없음 · 본사가 계정 발급 · 첫 로그인 비밀번호 변경 · 5회 실패 10분 잠금 |
| 파일 | 저장소 어댑터 — 컨펌: 로컬 폴더 / 운영: S3 호환 | 사진·캡처 이미지 |
| 외부 연동 | 어댑터 + 가짜 구현 | 아래 "외부 연동 자리" |
| 작업 처리 | `jobs` 테이블 + 앱 안 실행기 (컨펌) | 사진 처리·빌드·배포·색인 전송·재시도를 작업 로그로 보여 줌. 운영에서는 별도 워커로 분리 |

## 사용자와 권한

공개 회원가입은 없고, 본사가 계정을 만들어 전달합니다. 로그인 화면은 하나이고 계정 종류에 따라 이동합니다.

| 역할 | 들어가는 곳 | 범위 |
|---|---|---|
| 최고 관리자 | `/admin` | 전부 + 직원 계정 관리 · 요금제 편집 · 양산 범위 변경 |
| 관리팀 | `/admin` | 파트너 관리 · 검수 · 입금 확인 · 세금계산서 · 대행 작업 · 랜딩 관리 |
| 제작 담당 | `/admin` | 작업 로그 · 업종 템플릿 · 외부 연동 값 |
| 파트너 (업체당 1계정) | `/partner` | 자기 업체 데이터만 |

- 권한 표는 시안(`3n` 설정 · `PERMS`)을 그대로 씁니다. 화면과 서버 액션 둘 다에서 검사합니다.
- 파트너 데이터 분리: 모든 파트너 쿼리는 세션의 `partner_id`로만 거릅니다.
- 직원 계정은 삭제하지 않고 사용 중지합니다. 사용 중지 계정으로 로그인하면 "본사 담당자에게 연락해 주세요".
- 세션이 끝나면 로그인으로 보내고, 로그인 뒤 보던 화면으로 돌아옵니다(`?next=`, 같은 사이트 경로만).
- 다른 역할 주소로 들어오면 권한 없음 화면을 보여 줍니다.

## 주소

| 주소 | 화면 |
|---|---|
| `/` → `/landing/` | 가입 문의 랜딩 (지금 정적 파일 그대로) |
| `/login` | 로그인 · 첫 로그인 비밀번호 변경 |
| `/admin/...` | 본사 어드민 (시안 `현장로그 본사 어드민.dc.html`) |
| `/partner/...` | 파트너 관리자 — 데스크톱 사이드바 · 모바일 하단 탭 (시안 `현장로그 파트너 v2.dc.html`) |
| `/p/{slug}/...` | 파트너 공개 사이트 (컨펌용 임시 주소 · 색인 제외). 운영은 파트너 도메인 |
| `/api/...` | 랜딩 문의 받기 등 외부에서 들어오는 요청 |

화면별 주소는 [screens.md](screens.md)에 시안 번호와 함께 정리합니다.

## 외부 연동 자리

기획서 13장 "외부 승인 대비"대로, 승인 전에 자리를 다 만들어 두고 컨펌 단계에서는 가짜 구현으로 돕니다.

| 연동 | 컨펌 단계 | 운영 |
|---|---|---|
| 구글 드라이브 (사진 폴더) | 폴더 연결 상태·새 사진 수를 더미로 | Drive API |
| 사진 처리 (분류·중복·사람 표시) | 작업 로그에 결과만 기록 | 이미지 처리 워커 |
| 페이지 시안 생성 (AI) | 미리 만든 섹션 블록 조합 결과를 더미로 | 블록 조합 + 문구 생성 |
| 빌드 · 배포 · 도메인 | 상태 전이만 (연결 확인 데모) | 정적 빌드 + 호스팅 + 인증서 |
| IndexNow · 사이트맵 · 서치어드바이저 | 전송 기록만 · 유입 검색어 더미 | 실제 전송 · API 수집 |
| 알림톡 | 발송 기록만 | 템플릿 승인 후 코드 입력 |
| 온라인 결제 | 테스트 결제 흐름 | 결제사 실제 키 |
| 구글시트 동기화 | 동기화 기록만 | Sheets API (한 방향) |

설정값(색인 기간 안내 23일, 하루 발행 상한, 결제 키, 알림톡 템플릿 코드 등)은 `settings` 테이블에 두고 어드민 설정에서 바꿉니다.

## 폴더

```
design/            확정 시안 (로컬 · 공개 저장소 제외)
docs/              기술 구성 · DB 설계 · 화면 목록
site/              지금의 정적 랜딩 (Next 이전 전까지 그대로)
web/               Next.js 앱
  app/
    (auth)/login/          로그인 · 비밀번호 변경
    admin/                 본사 어드민
    partner/               파트너 관리자
    p/[slug]/              파트너 공개 사이트
    api/                   랜딩 문의 받기 등
  components/              공용 컴포넌트 (칩, 세그먼트, 스위치, 표, 페이지 넘김, 목록 상태 …)
  db/schema.ts             DB 스키마
  db/seed.ts               시안 더미 데이터
  lib/auth.ts              세션 · 권한
  lib/adapters/            외부 연동 어댑터 (가짜 구현 포함)
  styles/                  토큰 · 컴포넌트 CSS
```

랜딩(`site/`)은 Next 앱이 자리를 잡으면 `web/public/`으로 옮겨 같은 서버에서 띄우고, 랜딩 폼 주소(`config.js`의 `leadEndpoint`)를 Next API로 받습니다. 그때 `tools/dev-server.js`는 정리합니다.

## 진행 순서

1. 문서: 기술 구성(이 문서) · [DB 설계](db.md) · [화면 목록](screens.md)
2. 뼈대: Next 앱, 토큰·공용 컴포넌트, DB 스키마·시드, 로그인·세션·권한
3. 본사 어드민: 대시보드 → 가입 문의 → 파트너(목록·추가 4단계·상세·기능 스위치·도메인·결제) → 페이지 생성 → 업종 템플릿 → 요금제 → 발행·색인 → 검수 → 작업 로그 → 문의·정산 → 대행 작업 → 설정·직원 → 내 계정 → 랜딩 관리(시안 없음)
4. 파트너 관리자: 홈 → 현장 발행 → 사진 추가 → 검색 노출 → 만들고 있는 페이지 → 문의 → 블로그 → 결제 내역 → 설정 (데스크톱·모바일)
5. 랜딩을 Next로 옮기고 가입 문의 → 어드민 연결
6. 파트너 공개 사이트 (시안 컨펌 후)

## 컨펌 단계에서 하지 않는 것
- 실제 외부 API 호출, 실제 결제, 실제 문자·알림톡 발송
- 실제 사진 처리·AI 생성 (결과만 더미로)
- 운영 배포 설정 (회사 이전 때 정함)
