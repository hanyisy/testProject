# 컨펌용 더미 계정

모두 더미 데이터예요. 실제 업체·직원이 아니에요. 로그인 주소는 `/login`이고, 본사 계정은 **본사 어드민**(`/admin`), 파트너 계정은 **파트너 관리자**(`/partner`)로 들어가요.
로그인 화면 아래 "데모 계정으로 보기"에서 비밀번호 없이 바로 바꿔 들어갈 수도 있어요(`DEMO_LOGIN=off`로 끔).
